01 — Teacher

Prepare an examination

From paper to ready session in three decisions.

1

Create a class

Enter a class name and short code, then add each candidate and their exam code.

2

Add a paper

For a single written answer, add a PDF and prompt. For reading, listening or several questions, select paper.json and its assets together.

3

Start when ready

Choose the class and paper, set up the exam, then start it only when candidates are seated.

03 — Results

Close the loop

End the session; open every response.

During the exam

The teacher dashboard shows each session, submitted-candidate count and current online presence. A live connection refreshes the view as activity changes.

After the exam

End the session to submit outstanding work. Use View submissions to open each candidate response, then use the browser print dialog for a paper copy.

05 — Why local

Designed for classroom conditions

Simple infrastructure. Clear boundaries.

  • Runs on a school-network server rather than requiring students to create cloud accounts.
  • Works in ordinary browsers, managed Chrome and Safe Exam Browser setups.
  • Uses paper manifests so the exam interface can support distinct IB-style formats without bespoke screens.
  • Is an internal familiarisation product, not the IB Digital Examination System.
