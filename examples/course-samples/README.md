# DigitalDP course sample library

This directory contains two original DigitalDP example papers for each course currently exposed by the Paper Builder. The questions and source texts were authored for this project. They model common command terms, paper shapes, choice patterns, digital ink, source linking, and response lengths without reproducing IB questions, markschemes, artwork, or stationery.

Every paper is a custom familiarisation sample, not an official session paper. Candidate responses are entered directly beside their questions; none requires a separate answer sheet or answer booklet.

Run `bun run samples:build` to regenerate the editable manifests and ignored portable `.digitaldp-paper` files. Run `bun run samples:seed` to add any missing examples to the active local teacher library without duplicating titles already present.
